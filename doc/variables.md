### 러스트 변수는 기본적으로 불변

``` rust
- mut를 붙여서 가변으로 변경가능
ex1)
let x = 5;
x = 6 ;
 - 불변 값을 변경 할수 없음 컴파일 에러

ex2)
let mut x = 5;
x = 6;
 - 가변으로 으로 만들었기때문에 값의 변경 가능 - 컴파일 성공

!!! mut를 추가하는것은 미래에 다른 부분에서 변수가 변할것이라는 의도 전달 !!!
```

``` rust
상수(constant)

- 상수의 경우 mut와 함께 사용할수 없고
선언 키워드는 let키워드가 아닌 const 키워드

const THREE_HOURS_IN_SECONDS: u32 = 60 * 60 * 3;


!!! 값의 타입을 반드시 명시!!!
  - 상수는 전역 스코프를 포함한 어떤 스코프에서도 선언 가능하므로 코드의 많은 부분에서 알 필요가 있는 값에 유용
```

``` rust
섀도잉
-  새 변수를 이전 변수명과 같은 이름으로 선언
- 첫 번째 변수가 두 번째 변수에 의해 가려졌다 (shadowed) 라고 표현
- 스코프영역 기준으로 스코프가 끝나면 바깥쪽의 섀도잉 변수로 돌아옴

// 섀도잉
let z = 5;
let z = z + 1;
{
    let z = z * 2;
    // z = 12
    println!("The value of z in the inner scope is: {}", z);
}
// z = 6
println!("The value of z in the outer scope is: {}", z);

!!! mut과 섀도잉의 또 다른 차이점은 다시금 let 키워드를 사용하여 새로운 변수를 만드는 것이기 때문에 같은 변수명으로 다른 타입의 값을 저장할 수 있다는 것 !!!


```
